# Tbot Ultra

Tbot Ultra is distributed as a portable Windows application for Official Travian Legends servers.

## Download

Download the latest `tbot-ultra-win-x64-...-portable.zip` from [Releases](../../releases/latest).

1. Extract the complete zip to a writable folder, such as your Desktop.
2. Run `Tbot Ultra.exe` inside the extracted folder.
3. Create or sign in to your Tbot account in the application.
4. Add your Travian account under **Account → Manage**.

Do not download the `.sha256` file unless you want to verify the archive checksum. Do not move `Tbot Ultra.exe` out of its extracted folder because its bundled configuration, browser, and Playwright driver are required.

## Program copies

One Tbot account may register up to two separate program folders. Both may run on the same computer. Extract a separate portable folder for each copy; do not run two instances from the same folder.

## Updates

The application checks this repository's latest release and shows an update notification when a newer version is available. The notification opens or downloads the release from this repository.
